# Licenciamientos propuestos — en revisión

Este documento registra una propuesta y **no constituye una licencia aprobada
ni una autorización jurídica definitiva**.

| Componente | Propuesta | Estado |
|---|---|---|
| Código de la web y scripts | GPL-3.0-only | En revisión |
| Base de datos derivada | ODbL-1.0, sujeta a autorización de la fuente | En revisión |
| Documentación | CC BY-SA 4.0 | En revisión |
| Textos e imágenes | Por determinar | En revisión |
| Marcas y logotipos C+/UDD | Derechos reservados | No incluidos |

El repositorio `AleReb/data_Aysen_exports` no mostraba una licencia declarada
al momento de preparar esta plataforma. Antes de adoptar una licencia abierta
para los datos se debe confirmar la autorización del titular y la compatibilidad
con las condiciones de la fuente de Google/Looker Studio.

Mientras la revisión esté pendiente, los datos deben citar su fuente y no debe
inferirse una autorización general para redistribuir, sublicenciar o explotar
los contenidos.
